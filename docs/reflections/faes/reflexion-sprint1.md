# Inhalt (Auch Lektion 1!)

## 1.1. Welche verschiedenen Themen behandelten wir bis jetzt?
Wir hatten bis jetzt behandelt, was DevOps bedeutet, darin beinhaltet ist und wieso es relevant ist. 
Als erstes haben wir uns den Ablauf von CI/CD angeschaut. 
Anschliessend in den nächsten Lektionen schauten wir an, welche Tools diesen Ablauf erleichtern und beschleunigen.
Gelernte Themen:
- Linter: Ein Tool um einen gewissen Codestyle durchzusetzen, die Funktionalität des Codes zu gewährleisten und Good Practices durchzusetzen (Beispiel: Keine String Concat für SQL, sinnvolle Variabelnamen) 
- Formatter: Tool, um Code nach gewissen Richtlinien zu formatieren
- Github Actions: Workflows, welche zum Beispiel automatisch einen Release machen, den Code checken/linten und testen nach einem Commit
- Tools wie Kabal, ArgoCD, Jenkins zum einfachen Deployen von Applikationen

## 1.2. Was haben die Themen mit dem Begriff DevOps zu tun?
Alle diese Tools automatisieren und erleichtern den DevOps-Prozess, sodass die Entwickler sich mit wichtigeren Sachen beschäftigen können, wie zum Beispiel (Weiter)Entwicklung von Applikationen und Definieren neuer Aufgaben/Features.
Ausserdem erleichtern diese Tools den Einstieg in die Programmierung von Applikationen, welche diese Tools benutzen.
